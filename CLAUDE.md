## What this is

One static page (`site/index.html`, `site/style.css`) and the files GitHub
Pages needs (`site/CNAME`, `.github/workflows/pages.yml`). No generator, no
build, no JavaScript, no external resource: opening `site/index.html` in a
browser is the whole test. The manual lives elsewhere
(`docs.presk-lang.org`, built from the `presk` repository's `presk-manual`
crate); this site links to it.

`site/gpt/index.html` is the one exception to "no JavaScript": the pipeline
view of the course GPT, a document the compiler wrote (`presk explain
--format html` at 0.17.1 on the entry `logits` of `experiments/margins.psk`,
the page the talks' screenshots were taken from), copied byte for byte (the
user, 2026-11-13). It is one self-contained file (its scripts, KaTeX and
fonts inline, no request to another host). Never edit it. To replace it,
run the compiler again (`presk-project/docs/pipeline-view-local.sh` with
`TAG=<version>` writes `out/explain/logits/explain.html`), check the file
for local paths and names before copying it, and bring the numbers of the
landing page's section "A whole network" and the checksum in its comment to
the new file. The files the page names beside it (`listings/`, `artifacts/`)
are not published: the exported C program's README and its conformance
script print the absolute path of the directory they were written in.

## Rules

- **What is said about Presk is the project's own wording**: the report's
  chapters in `presk-specs` for what it is, the latest
  `presk-specs/docs/status-*.md` for where it stands (its plain-language
  section is the model), the compiler's manual for what exists. No claim
  on this site that a decision or a report does not hold, no number typed
  from memory; what fails is said to fail.
- **Nothing from `presk-project`** (transcripts, chats, archives) and
  nothing that the publication note keeps private
  (`presk-project/docs/publication-2026-09-25.md`, addendum 2026-09-26).
- **While a paper is under double-blind review**, the site may exist and
  change, but nothing is announced from it and the paper is not mentioned
  until notification; the paper never links the site.
- Links to `github.com/presk-lang/...` name repositories that exist and are
  public at the time of the change; a link to a private or absent
  repository is removed, not left as a promise.
- No PDF on the site for now (the user, 2026-11-11: the report and the
  reference were removed). If PDFs come back, they are copies of built
  documents of `presk-specs`, named with their date; the source of truth
  stays there.
- Git: `origin` is the GitLab and is where work goes, as in the sibling
  repos: a branch per change, a merge request through `gas-forge`; the
  user merges. The user pushes `main` to `github`; **the agent never pushes
  to GitHub**. `git status` and `git log --oneline -5` before editing.
