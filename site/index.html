Presk

A language for neural networks with an exact meaning, compiled under a declared error budget.

What it is An example Where it stands Documents Source Cite

What it is

A Presk program denotes a mathematical function over tensors of real numbers. The language has no machine number type: no float32, no bfloat16. Shapes, with named and symbolic axes, are part of the types and are checked before anything runs; every function carries a regularity class that decides whether it may be differentiated; randomness is an explicit effect.

Precision is a compilation choice. The author declares an error budget on a result, and the compiler chooses, site by site, the machine types and the order of operations that meet it, then checks the choice by measurement against an exact reference. A rewrite the optimizer applies changes nothing over the reals; an approximation is always declared, and bounded.

Training and inference are derived from the same program, not written twice. The compiler is written in Rust and generates native code.

An example

module LayerNorm{D : dim} {
  param γ : ℝ[D]  init = ones     -- gain
  param β : ℝ[D]  init = zeros    -- bias

  -- eps is not a numerical guard: the semantics is exact. It is a
  -- hyperparameter of the model. The stability of sqrt and of the
  -- division is the compiler's, under the budget.
  fn apply(x : ℝ[..., model: D], eps : f64 = 1e-5) -> ℝ[..., model: D] =
    let μ  = mean(axis model, x)
    let σ2 = mean(axis model, (x - μ)^2)
    let x̂  = (x - μ) / sqrt(σ2 + real(eps))
    x̂ * γ + β
}

A layer norm over a symbolic model dimension D, checked once for every D: the program of the specification's examples, which the compiler checks as its test suite.

Where it stands

Presk is a research project at Mines Paris – PSL, at the scale of a doctoral thesis. The compiler exists, with a reference interpreter that computes the exact meaning of a program, a native backend, training and serving, an optimizer over exact rewrites, a solver for error budgets, and a PyTorch export. It has been tested on statements fixed in advance:

  • A budget on one training step bought a factor of about two over computing everything in double precision, with the error measured against the exact reference. Integer weights hold a measured error. BERT-large runs at the published constants with an exact reference.
  • A static cost model, frozen before the measurements, ranks the fastest arrangements of an attention kernel correctly on more than nine close comparisons in ten on one kind of core, and on about seven in eight on new shapes, short of the target set for it. Used as a filter, it finds an arrangement within 3 % of the best for under 2 % of the cost of timing every one.
  • Training speed is well behind PyTorch. The GPU has not started.

Source

The compiler is published under the Apache-2.0 license at github.com/presk-lang/presk, and the specification, with the example programs that are the compiler's test suite, at github.com/presk-lang/presk-specs. The public branch holds the front-end (the parser, the type checker with its decidable fragment of shape arithmetic, and presk check); the rest of the compiler follows.
